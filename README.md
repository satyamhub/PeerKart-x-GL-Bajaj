# PeerKart x G.L BAJAJ

Official Android APK releases for the PeerKart campus marketplace.

## Download

Open the [latest release](https://github.com/satyamhub/PeerKart-x-GL-Bajaj/releases/latest) and download the APK asset. Android will ask you to confirm installation. Updates install over an existing PeerKart app when they are signed with the same app signing key.

## Automatic updates

The app checks the `latest.json` file in this repository and downloads versioned APK assets from GitHub Releases. APKs are verified by SHA-256 before Android's installer opens.

## About this repository

This repository hosts release files and update metadata only. The PeerKart application source is maintained separately.
