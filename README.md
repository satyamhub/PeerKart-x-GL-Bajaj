## What you can do

- Browse items listed for the campus community.
- Chat with a seller about a specific listing.
- Save listings and get in-app updates.
- Eligible campus sellers can publish listings with photos and pickup details.
- Sign in using your student ID and verify your account by email OTP.

## Download

Open [PeerKart on the web](https://glbpeerkart.netlify.app), or download the latest Android APK from [GitHub Releases](https://github.com/satyamhub/PeerKart-x-GL-Bajaj/releases/latest).

Android may ask you to allow installation from your browser or file manager. Review the install prompt and confirm to install the app.
